PrimalSphere GitHub Pages版 v1.1

使い方:
1. このZIPを解凍
2. GitHubで新しいリポジトリを作成
3. index.html / manifest.json / service-worker.js / icon.svg をアップロード
4. Settings → Pages → Deploy from a branch → main / root を選ぶ
5. 表示されたURLをAndroid Chromeで開く
6. 右上メニューから「ホーム画面に追加」

注意:
- 編集データはブラウザ内に自動保存されます。
- 確実に残すには、アプリ内の「保存」から primalsphere_data.json を保存してください。
- 別端末では「読込」からJSONを読み込んでください。
